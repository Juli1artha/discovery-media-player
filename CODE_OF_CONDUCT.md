# Code of conduct

**Be straightforward and assume competence.**

Technical disagreement is welcome and is settled with evidence — a failing test, a log, a spec.
"This is wrong, here is the case that breaks it" is a good message. Nobody here needs their
message wrapped in three paragraphs of courtesy, and nobody gets to skip the evidence because
they said it forcefully.

## What is not acceptable

- Personal attacks, insults, or harassment — in an issue, a review, a discussion, or anywhere
  you are representing this project.
- Publishing someone's private information.
- Sustained disruption: derailing threads, reopening settled decisions without new evidence,
  demanding attention as if it were owed.

Being right is not a defence. A correct point delivered as an attack gets moderated like an
attack.

## Scope

Every project space: issues, pull requests, discussions, code review, and the commit history.

## Enforcement

Report conduct problems to **security@3d-discovery.fr** — the same monitored address as
security reports, so nothing lands in an inbox nobody reads. Reports are read by the
maintainers, kept confidential, and answered within 72 hours.

Consequences scale with the behaviour: a warning, then removal of the offending content, then a
ban. A maintainer involved in the incident does not judge it.

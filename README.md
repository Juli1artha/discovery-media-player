# Signatures du CLA

Cette branche ne contient **que** le registre des signatures du
[CLA](https://github.com/Juli1artha/discovery-media-player/blob/main/CLA.md), écrit par le bot
lorsqu'un contributeur signe. Elle est volontairement séparée de `main` : l'historique du code
raconte le code, pas les paraphes.

⚠️ **Ne pas protéger cette branche.** Le bot doit pouvoir y écrire, et une protection le fait
échouer avec un message qui ressemble à un défaut de configuration du CLA lui-même.

Chaque entrée porte le nom, l'identifiant GitHub, la date et le commit au moment de la signature.
Un contributeur qui veut relire ce qu'il a signé le trouve ici.
